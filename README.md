## Descripción

En esta actividad trabajamos con estructuras (struct) en C++ para modelar una entidad con diferentes tipos de datos.

También utilizamos punteros, pasaje por referencia y el operador flecha (->) para acceder y modificar los datos de la estructura.

## Modelo utilizado

La estructura `EntidadProyecto` contiene:

- `id`: identificador de la entidad.
- `nombre`: nombre o descripción.
- `metrica`: valor numérico de la entidad.
